FOR MY PICHIDHI — website files

Preview on your computer:
1. Extract this ZIP.
2. Open the pichidhi_love_website folder.
3. Double-click index.html. It opens in your browser.

Free online hosting with GitHub Pages:
1. Sign in or create a GitHub account.
2. Create a new PUBLIC repository named pichidhi-love (or any name).
3. Upload index.html and the entire photos folder (keep the same folder structure).
4. In the repository, open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose main and / (root), then Save.
7. Wait a few minutes; GitHub will show the website URL in Settings → Pages.

Important:
- This is a static website and needs no paid hosting or music.
- GitHub Pages can stay free, but no service can guarantee that a site will exist forever.
- Keep a backup of this ZIP and the photos.
- The photos are included in the ZIP; do not upload only index.html.
